# 됴듀 커플 웹페이지 올리는 방법

코딩을 수정할 필요 없이 이 폴더 안의 파일을 전부 GitHub에 올리면 됩니다.

1. GitHub에 로그인한 뒤 오른쪽 위 `+` → `New repository`를 누릅니다.
2. Repository name에 `dyodyu-love-page`를 입력합니다.
3. `Public`을 선택하고 `Create repository`를 누릅니다.
4. 새 저장소에서 `uploading an existing file`을 누릅니다.
5. 이 압축파일을 먼저 푼 다음, `dyodyu-love-page` 폴더 안의 파일과 폴더를 전부 끌어다 놓습니다.
6. 아래쪽 `Commit changes`를 누릅니다.
7. 위 메뉴의 `Settings` → 왼쪽 `Pages`로 들어갑니다.
8. `Build and deployment`의 Source는 `Deploy from a branch`, Branch는 `main`과 `/(root)`를 선택하고 `Save`를 누릅니다.
9. 1~5분 뒤 같은 화면에 표시되는 주소를 열면 완성입니다.

## 꼭 기억하기

- `index.html`, `images` 폴더, `music` 폴더가 모두 같은 위치에 있어야 합니다.
- 브라우저 정책상 음악은 자동으로 재생되지 않습니다. 첫 화면의 버튼을 누르면 시작됩니다.
- 저장소가 Public이면 주소를 아는 사람뿐 아니라 검색을 통해 다른 사람이 볼 가능성도 있습니다. 실제 사진이나 개인정보를 추가할 때 주의하세요.
